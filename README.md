# Creating Users in Microsoft Entra ID

## Project Overview

In this lab, I practiced creating and verifying a new user account in Microsoft Entra ID. The goal was to gain hands-on experience with user provisioning and understand how cloud identities are configured and added to an Entra ID tenant.

## Technologies Used

- Microsoft Entra ID
- Microsoft Azure
- Identity and Access Management (IAM)

## What I Practiced

- Navigating the Microsoft Entra admin center
- Creating a new internal user account
- Configuring a user principal name and display name
- Keeping the account enabled
- Reviewing account information before creation
- Verifying that the new user was successfully added to the tenant

## Step 1: Create a New User

I navigated to **Microsoft Entra ID > Users > New user > Create new user**.

I entered the information for a test account, including the user principal name and display name. I kept the account enabled and used the auto-generated password option.

![Create New User](images/01-create-new-user.png)

## Step 2: Review the User Configuration

Before creating the account, I reviewed the user information to confirm that the user principal name, display name, account status, and user type were correct.

This step helped me understand the importance of verifying account information before provisioning a user.

![Review User Configuration](images/02-review-user-configuration.png)

## Step 3: Verify the User Was Created

After creating the account, I returned to the **All users** page and confirmed that the new test user, **Taylor Morgan**, was successfully added to the Microsoft Entra ID tenant.

![User Created Successfully](images/03-user-created-successfully.png)
